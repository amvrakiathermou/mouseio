Ενημέρωση από το ίντερνετ
Τοπική λειτουργία (από συσκευή)

Πώς στέλνω νέα δεδομένα στο GitHub

Φτιάχνουμε φάκελο στον υπολογιστή μας και τον ονομάζουμε mouseio amvrakia. Μέσα του έχει το Excel mouseio amvrakia excel και τον φάκελο github-mouseio, με τρεις υποφακέλους: img (φωτογραφίες), audio (mp3), video (mp4, έως 25 MB το καθένα).

1. Ετοίμασε τα αρχεία στον υπολογιστή

  • Συμπλήρωσε σωστά το Excel. Το ID κάθε εγγραφής είναι και το όνομα του αρχείου: P012 → P012.jpg, A007 → A007.mp3, V004 → V004.mp4.
  • Ονόμασε τα αρχεία που θες να ανεβάσεις σύμφωνα με το Excel και βάλ’ τα στον φάκελο Desktop\mouseio amvrakia\github-mouseio (img οι φωτογραφίες, audio τα mp3, video τα βίντεο).

2. Μετατροπή και προετοιμασία για upload

  • Πάτα [Διάλεξε φάκελο: mouseio amvrakia] — τον φάκελο που έχει μέσα το Excel και τον υποφάκελο github-mouseio. Ο browser θα ρωτήσει αν επιτρέπεις την επεξεργασία αρχείων στον φάκελο: πάτα «Επιτρέπω». Διάβασε την αναφορά, διόρθωσε ό,τι έχει ⚠ και ξαναπάτα, μέχρι να γράψει ✔.

Φάκελος = Excel + github-mouseio μαζί. «Μόνο Excel» = φτιάχνει data.json χωρίς έλεγχο φωτογραφιών/ήχων.

  • Πάτα [Λήψη data.json]. Το αρχείο αποθηκεύεται αμέσως μέσα στον φάκελο github-mouseio (στη θέση του παλιού), όχι στις Λήψεις. Αν ο browser δεν το υποστηρίζει (π.χ. Firefox), κατεβαίνει στις Λήψεις και σου το λέει: τότε βάλε το εσύ στον φάκελο github-mouseio.

3. Ανέβασέ τα στο GitHub

  • Άνοιξε το GitHub και συνδέσου αν σου ζητηθεί:
    https://github.com/amvrakiathermou/mouseio
  • Ανέβασε τα νέα αρχεία. Για καθέναν από τους φακέλους img, audio, video: μπες στον φάκελο → Add file → Upload files → σύρε μόνο τα νέα ή αλλαγμένα αρχεία → κάτω πάτα το πράσινο Commit changes. (Έως περίπου 100 αρχεία τη φορά.)
  • Ανέβασε το data.json (από τον φάκελο github-mouseio): Add file → Upload files → σύρε το data.json (αντικαθιστά το παλιό) → Commit changes.
  • Περίμενε 3–5 λεπτά μέχρι να δημοσιευτούν οι αλλαγές.

4. Ενημέρωση όλων των tablet

  • Έλεγχος: άνοιξε https://amvrakiathermou.github.io/mouseio/data.json και δες ότι έχει το νέο περιεχόμενο.
  • Σε tablet με wifi πάτα Ενημέρωση από το ίντερνετ: κατεβάζει μόνο ό,τι άλλαξε (και τα βίντεο).
  • Τα κινητά (QR) τα βλέπουν αμέσως.

Πώς στέλνω νέα δεδομένα στη συσκευή (tablet χωρίς ίντερνετ)

  1. Περίμενε να φτιαχτεί το αρχείο paketo-mouseiou.zip. Αν είναι μεγάλο, θέλει λίγη ώρα. Μην κλείσεις τη σελίδα. Θα κατέβει στον φάκελο Λήψεις.
  2. Πέρασε το αρχείο στο tablet: με καλώδιο USB (στο tablet διάλεξε «Μεταφορά αρχείων») στον φάκελο Λήψεις, ή με κάρτα μνήμης.
  3. Στο tablet άνοιξε το μενού προσωπικού → «Ενημερώσεις & Δεδομένα» → Φόρτωση από τη συσκευή → διάλεξε το paketo-mouseiou.zip.
  4. Περίμενε να γράψει «Αποθήκευση Χ/Υ». Όταν τελειώσει, η εφαρμογή ξαναφορτώνει μόνη της.
  5. Έλεγχος: στις «Πληροφορίες έκδοσης» πρέπει να γράφει «Λειτουργία: τοπική» και όλα τα αρχεία αποθηκευμένα (✔).
  6. Σβήσε το .zip από το tablet, για να ελευθερωθεί χώρος.
Προσοχή: ένα tablet σε τοπική λειτουργία δεν παίρνει ενημερώσεις από το GitHub. Για να γυρίσει στο ίντερνετ επίλεξε Ενημέρωση από το ίντερνετ παραπάνω.

Η εφαρμογή έκλεισε. Το tablet είναι πλέον ξεκλείδωτο.
